# Market Intelligence Agent

This repository contains the .NET services that extend Dify for the marketing
intelligence agent. Dify remains responsible for the conversation experience,
knowledge bases, RAG, and workflow orchestration. This solution hosts only the
custom capabilities that will later provide collection, transcription, OCR,
media composition, scheduling, and delivery.

## Solution Layout

- `src/MarketIntelligence.Agent.Api`: HTTP entry point for Dify workflows and internal callers.
- `src/MarketIntelligence.Agent.Application`: use cases and provider-independent interfaces.
- `src/MarketIntelligence.Agent.Infrastructure`: adapters for Dify and external providers.
- `src/MarketIntelligence.Agent.Worker`: background host for scheduled and long-running work.
- `tests/MarketIntelligence.Agent.Tests`: in-memory API contract tests.

## Development

Open `MarketIntelligence.Agent.sln` in JetBrains Rider, then run the API or Worker launch configuration generated by Rider.

```powershell
dotnet restore MarketIntelligence.Agent.sln
dotnet build MarketIntelligence.Agent.sln --configuration Release -m:1 -p:NuGetAudit=false
dotnet test MarketIntelligence.Agent.sln --configuration Release -m:1 -p:NuGetAudit=false
```

The `-m:1` option is required in this local environment to avoid concurrent
MSBuild intermediate-file locks. Credentials, endpoint URLs, scraped data,
media, and model files must remain outside the repository.
