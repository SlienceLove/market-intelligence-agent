# 本地 ASR、OCR 与 TTS 验证记录

**验证日期:** 2026-08-10  
**范围:** 无云平台授权条件下的本地 CPU 可行性验证。模型、虚拟环境、音频和图片 fixture 均位于系统临时目录，未提交到仓库。

## 环境与方法

- Windows 主机，AMD Ryzen 7 H 255（8 核 / 16 逻辑处理器），无 NVIDIA GPU。
- Python 3.13.2；所有依赖放在相互隔离的临时 venv 中。
- 不发送业务数据，不调用付费云 API。模型首次下载不计入稳态推理实时率。
- CER 为去除空白和标点后的字符错误率。TTS 回读 CER 仅用于粗略比较可懂度，不能代替人工试听、MOS 或真实业务语料验收。

## ASR：faster-whisper

| 项目 | 结果 |
|---|---|
| 运行时 | `faster-whisper` 1.2.1，`Systran/faster-whisper-base` |
| 配置 | CPU，`int8`，8 推理线程 |
| fixture | 7.762 秒中文合成 WAV，22,050 Hz，30 个参考字符 |
| 首次模型准备 | 334.162 秒，主要为匿名模型下载 |
| 首次转写 | 0.959 秒，RTF 0.124 |
| 热转写 | 0.906 秒，RTF 0.117 |
| 结果 | 2 个片段，语言置信度 1.0，时间轴合法，CER 0.3667 |

结论：本机 CPU 已可稳定跑通本地 ASR，稳态速度满足短视频和批处理 PoC。该 fixture 使用 Windows 中文合成音，且输出含简繁转换和同音误识，不能代表真人、方言、噪声或业务领域音频的准确率。后续应以授权真人样本分别测普通话、背景噪声、多人声和术语 CER。

## OCR：RapidOCR / PaddleOCR ONNX 模型

| 项目 | 结果 |
|---|---|
| 运行时 | `rapidocr-onnxruntime` 1.2.3，CPU ONNX Runtime |
| 模型 | `ch_PP-OCRv3` 检测与识别，`ch_ppocr_mobile_v2.0` 方向分类 |
| fixture | 1,600 x 720 中英数字混排截图，3 行，30 个参考字符 |
| 引擎准备 | 0.822 秒 |
| 首次识别 | 0.648 秒：检测 0.383 秒、方向分类 0.004 秒、识别 0.187 秒 |
| 热识别 | 0.298 秒 |
| 结果 | 3 个文字块，CER 0，坐标均在图像范围内，置信度 0.8450 至 0.8555，重复结果一致 |

结论：轻量 ONNX 路径在当前 Python 3.13 / Windows CPU 环境已验证可用，适合作为本地 OCR PoC。后续需用授权视频帧验证小字号、遮挡、低对比度、运动模糊和重复帧去重阈值。

## TTS：sherpa-onnx 中文 VITS

统一 fixture 为 219 字、8 句的脱敏中文文本，CPU 4 线程，语速 1.0。音频仅写入临时目录。

| 模型 | 输出 | 首次 / 热生成 | RTF | 回读 CER | 结论 |
|---|---:|---:|---:|---:|---|
| `vits-icefall-zh-aishell3` | 8,000 Hz，47.511 秒 | 1.549 / 1.559 秒 | 0.033 / 0.033 | 0.6667 | 极轻量 smoke test 可用，音质 / 可懂度不足以作为默认旁白 |
| `sherpa-onnx-vits-zh-ll` | 16,000 Hz，41.180 秒 | 9.564 / 8.759 秒 | 0.232 / 0.214 | 0.2289 | 当前本机更适合中文旁白 PoC，仍需人工试听和授权核验 |

两个模型均产生非空、有限数值的 WAV；回读 ASR 时间轴合法。`zh-ll` 的回读 CER 明显更低，但该指标仍不是声音自然度或音色合规的充分证据。

## 成本、许可证与推荐

| 能力 | 当前推荐 | 直接成本 | 上线前边界 |
|---|---|---|---|
| ASR | `faster-whisper/base`，CPU `int8` | 本地算力和一次模型下载；无按调用计费 | `faster-whisper` 代码包声明 MIT；转换后的模型与全部依赖的 NOTICE 需随发布物复核 |
| OCR | `rapidocr-onnxruntime` + `ch_PP-OCRv3` ONNX | 本地算力；无按调用计费 | 运行时声明 Apache-2.0；模型来源和依赖 NOTICE 需纳入发布清单 |
| TTS | 代码链路默认使用 `placeholder` 占位后端，真实模型仅在授权确认后通过配置切换 | 本地算力；占位后端无模型依赖 | 当前模型归档没有足以完成商业授权判断的许可材料，因此业务代码不绑定任何具体模型名、模型路径或音色 ID |

推荐下一步：

1. 已完成 `faster-whisper` 本地 sidecar HTTP smoke：经现有 API、队列和 `HttpTranscriptionService` 调用后返回 2 个合法时间片段。下一步将 sidecar 部署到受控共享媒体根目录，并以授权真人样本验收。
2. 已完成 RapidOCR 单图片本地 sidecar HTTP smoke；下一步接入受控视频帧采样，并用授权视频帧验收小字号、遮挡和运动模糊。
3. TTS 在选定具有明确商用音色授权的模型前保持 PoC 状态；通过人工试听和授权审查后，再将选定模型封装为 sidecar provider。
4. 使用不少于 30 分钟的授权中文媒体样本完成质量门槛：ASR 分场景 CER、OCR 字符召回 / 坐标准确率、TTS 人工可懂度与音画同步偏移。

## 未纳入本次结论

- 无授权云 ASR、OCR、TTS 平台没有被调用或比较。
- 未安装 FFmpeg，因此尚未执行真实音画合成 smoke test。
- 本次不构成模型、音色、训练数据或第三方依赖的商用许可意见。
- 2026-08-10 视频帧抽取 smoke：使用用户范围安装的 `Gyan.FFmpeg.Essentials 8.1.1` 生成 3 秒本地合成视频，按 1 fps 抽取 3 张 JPEG；RapidOCR sidecar 返回 3 个文本框，最低置信度 `0.7991`。该 fixture 仅验证抽帧边界和链路，不代表授权业务视频质量。
